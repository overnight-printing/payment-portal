# Portal presentation rules

Retain navy #1e2f66, blue accents, white surfaces, current success/warning/error colors, Arial/Helvetica and the supplied Overnight Printing logo. Use the installed upstream UI/UX skill as guidance, with owner requirements taking precedence.

| Element | Rule |
| --- | --- |
| Buttons, inputs, selects, icon actions | 44px minimum height, 8px radius, common 14px button type; inputs stay 16px on mobile |
| Icons | Existing outline family; 18px in controls, 20px navigation, 24px decorative upload symbol |
| Spacing | 8px action gaps, 16px within forms, 24px section/page gutters; 16px mobile gutters |
| Data tables | 13–14px text, status labels >=12px, 44px targets and compact rows; amounts align right on desktop |
| Cards | White surfaces, consistent border/radius and restrained shadow; avoid unrelated decorative treatments |
| Layout | Clear heading/actions, aligned search/date/email row; consistent navigation and drawer sections |
| Responsive | Full-width workspace; scroll region only for narrow desktop tables, all fields/actions in mobile cards; no page overflow |
| Preservation | Keep every route, field, filter, action, handler, disabled/recovery state, print and payment contract |

Verified skill guidance: Minimalism & Swiss Style, touch target spacing, compact label overflow, visible labels, React accessible test queries. Dark/glass generated marketing directions were excluded from this portal's retained design. No new UI framework, font download or dependency.
